01

先学三个知识点

秩和核空间

把矩阵 B 看作方程组的系数。做行变换时，可以交换两行、把某行乘以非零常数，或把某行的倍数加到另一行。这三种操作都能撤销，所以不会改变 Bx = 0 的解。

  1. 先消元。 找到当前列中可用的非零数当主元，把它下面的数消成 0，再往右下处理。零行放到底部。
  2. 再数主元。 阶梯形矩阵有几个主元，秩就是几。没有主元的列对应自由变量。若有 n 列和 r 个主元，核的维数就是 n − r。
  3. 最后回代。 把非零行写回方程。若有两个自由变量 s、t，分别取 (s,t) = (1,0) 和 (0,1)，代回去得到两个基向量。再用任意 s、t 写出通解。
基础解系和通解

基础解系是一组向量。通解是把这些向量乘任意系数再相加，表示所有解。

特征值和特征向量

若非零向量 v 满足 Av = λv，λ 就是对应的特征值。把右边移到左边得 (A − λI)v = 0。因为要有非零解，A − λI 必须不可逆，所以先令 det(A − λI) = 0，再对每个 λ 解方程组。

I 是单位矩阵。构造 A − λI 时，只把对角线上的元素减去 λ。三角矩阵可以直接从对角线读出特征值，求特征向量仍要解方程。

向量和矩阵范数

先逐项取模。比如 |2 − 2i| = √(2² + (−2)²) = 2√2。然后看题目里的是向量还是矩阵。

02

跟做一道特征向量题

求下面这个矩阵的特征值，以及每个特征值对应的一个非零特征向量。

A = 2103
  1. 写出 A − λI。 对角线上分别做 2 − λ 和 3 − λ，其他位置保持原数。
    A − λI = 2103 − λ1001 = 2 − λ103 − λ
  2. 算行列式并令它为零。 二阶行列式是主对角线乘积减去副对角线乘积，所以
    det(A − λI) = (2 − λ)(3 − λ) − 1·0 = 0
    两个因子里至少有一个为零，得 λ = 2 或 λ = 3。
  3. 代入 λ = 2，逐行写方程。
    0101x₁x₂ = 00
    第一行给 0·x₁ + x₂ = 0，第二行也是 x₂ = 0。因此 x₂ 必须为 0，x₁ 可自由取值。为了得到非零向量，取 x₁ = 1，得 v₁ = (1, 0)ᵀ。

    验算：Av₁ = (2·1 + 1·0, 0·1 + 3·0)ᵀ = (2, 0)ᵀ = 2v₁。

  4. 代入 λ = 3，逐行写方程。
    −1100x₁x₂ = 00
    第一行给 −x₁ + x₂ = 0，第二行给 0 = 0，没有新增限制。因此 x₂ = x₁。取 x₁ = 1，就有 x₂ = 1，得 v₂ = (1, 1)ᵀ。

    验算：Av₂ = (2·1 + 1·1, 0·1 + 3·1)ᵀ = (3, 3)ᵀ = 3v₂。

现在盖住例题

重新写一遍 λ = 3 时的矩阵和两行方程。然后去做第 2 题，把这个流程用到另一组数字上。

03

独立练四道题

先在空白处或草稿纸上写。卡住时只展开提示。第 3、4 题是按往年题型改编的练习。

01

基础题

行化简求秩和核

B = 121242011

求 B 的秩、核的维数，以及核的一组基。

看起手提示

先把第二行减去第一行的两倍，再把零行移到底部。

看逐步答案与讲解

解题路线 行化简找主元 → 数秩和自由变量 → 写通解和基础解系 → 验算。

  1. 用第一行消掉第二行的首项

    把三行记作 R₁、R₂、R₃。第二行的第一个数 2 是第一行首项 1 的两倍，所以用 R₂ − 2R₁。把某行的倍数加到另一行可以反向撤销，因此不改变 Bx = 0 的解。

    (2, 4, 2) − 2(1, 2, 1) = (2 − 2, 4 − 4, 2 − 2) = (0, 0, 0)

  2. 把零行移到底部

    第三行的首项已经是 0，不用再消第一列。交换第二、三行后，非零行的首个非零项依次在第 1、2 列，已经是阶梯形，不必再消第一行里的 2。

    121242011 → 121000011 → 121011000

  3. 数主元和自由变量

    第一、二列各有一个主元，所以秩是 2。第三列没有主元，对应的 x₃ 是自由变量。三个未知量里有两个主元变量，剩下一个自由变量，所以核的维数是 1。

    rank(B) = 2，dim ker(B) = 3 − 2 = 1

  4. 把两条非零行写成方程

    第 1 行给 x₁ + 2x₂ + x₃ = 0，第 2 行给 x₂ + x₃ = 0，第 3 行给 0 = 0。最后一行不增加约束，所以从更短的第 2 个方程开始回代。

    设 x₃ = t，则 x₂ + t = 0，得到 x₂ = −t。
    代入第一个方程：x₁ + 2(−t) + t = 0，即 x₁ − t = 0，所以 x₁ = t。

  5. 区分通解和一组基

    任意 t 都给出一个解，这些解都是同一个非零向量的倍数。取 t = 1，得到的向量可以生成所有解，因此它单独就构成核的一组基。

    x = (t, −t, t)ᵀ = t(1, −1, 1)ᵀ，基础解系为 {(1, −1, 1)ᵀ}

  6. 用原矩阵验算

    把 (1, −1, 1)ᵀ 代回原来的 B。乘积的每个分量是一行和这个列向量对应相乘再相加。

    第一行：1·1 + 2·(−1) + 1·1 = 0。
    第二行：2·1 + 4·(−1) + 2·1 = 0。
    第三行：0·1 + 1·(−1) + 1·1 = 0。

容易丢分的地方 第三列虽然有非零数，却没有主元。判断自由变量看的是阶梯形里的主元位置。

02

基础题

求特征值和特征向量

C = 1103

求两个特征值，各写出一个对应的非零特征向量。

看起手提示

C 是上三角矩阵。读出特征值后，分别写出 C − I 和 C − 3I。

看逐步答案与讲解

解题路线 找特征值 → 每个特征值各解一次齐次方程组 → 用 Cv = λv 验算。

  1. 用行列式找特征值

    特征向量必须非零。要让 (C − λI)v = 0 有非零解，C − λI 就必须不可逆，行列式为零。二阶行列式用主对角线乘积减副对角线乘积。

    C − λI = 1 − λ103 − λ
    det(C − λI) = (1 − λ)(3 − λ) − 1·0 = 0

    两个因子至少一个为零，所以 λ = 1 或 λ = 3。下次见到上三角矩阵，也可以直接读对角线。

  2. 代入 λ = 1 并逐行读方程

    只把对角元减 1，右上角的 1 照抄。用得到的矩阵乘 x = (x₁, x₂)ᵀ，右边是零向量。

    0102x₁x₂ = 00

    第一行：0·x₁ + 1·x₂ = 0，所以 x₂ = 0。
    第二行：0·x₁ + 2·x₂ = 0，也要求 x₂ = 0。

  3. 为 λ = 1 选非零向量并验算

    方程没有限制 x₁。取 x₁ = 1、x₂ = 0，得到 v₁ = (1, 0)ᵀ。乘回原矩阵，比较它与 1·v₁ 是否相同。

    Cv₁ = (1·1 + 1·0, 0·1 + 3·0)ᵀ = (1, 0)ᵀ = 1·v₁

  4. 代入 λ = 3 并逐行读方程

    对角线分别变成 1 − 3 = −2、3 − 3 = 0，右上角仍是 1。

    −2100x₁x₂ = 00

    第一行：−2x₁ + x₂ = 0，所以 x₂ = 2x₁。
    第二行：0·x₁ + 0·x₂ = 0，对任何 x₁、x₂ 都成立，不增加约束。

  5. 为 λ = 3 选非零向量并验算

    取 x₁ = 1，按 x₂ = 2x₁ 算出 x₂ = 2，得到 v₂ = (1, 2)ᵀ。

    Cv₂ = (1·1 + 1·2, 0·1 + 3·2)ᵀ = (3, 6)ᵀ = 3v₂

容易丢分的地方 不能把两个变量都取成 0。任何非零倍数仍是同一特征值的特征向量，比如 (2, 4)ᵀ 也可作为 λ = 3 的答案。

03

按往年题型改编

算复矩阵的最大行和

D = 11 + 2i2 − 2i3

求矩阵 ∞ 范数 ‖D‖∞。

看起手提示

分别取四个元素的模。先在每一行内部相加，再在两行之间比较。

看逐步答案与讲解

解题路线 先逐项取模 → 分别求两行的和 → 比较并取最大。

  1. 认出题目要按行算

    D 是矩阵，题目要的是 ∞ 范数，因此先算每一行的模之和。每行得到一个实数，最后才取最大。

    ‖D‖∞ = max(第一行模之和，第二行模之和)

  2. 算第一行

    实数 1 的模是 1。对复数 1 + 2i，实部是 1、虚部是 2，用 |a + bi| = √(a² + b²)。

    |1| + |1 + 2i| = 1 + √(1² + 2²) = 1 + √5

  3. 算第二行

    2 − 2i 的虚部是 −2。虚部平方后是 4，所以这个元素的模是 √8 = 2√2。右边实数 3 的模是 3。

    |2 − 2i| + |3| = √(2² + (−2)²) + 3 = 2√2 + 3

  4. 比较两行并写答案

    第二行的实数项 3 大于第一行的 1，根号项 √8 也大于 √5，因此第二行的和更大。

    ‖D‖∞ = 3 + 2√2

容易丢分的地方 要先对每个元素取模，再在同一行相加。若先把复数相加再取模，实部和虚部可能互相抵消。

04

按往年题型改编

分开算三种范数

A = 1i0i−120i1， b = 12i1

求 ‖b‖1 + ‖Ab‖∞ + ‖A‖1。

看起手提示

先算 b 的模之和，再算 Ab。最后一项按列求和。

看逐步答案与讲解

解题路线 依次算向量 b 的 1 范数、向量 Ab 的 ∞ 范数、矩阵 A 的 1 范数。

  1. 先分清三个对象

    b 和 Ab 都是列向量，因此分别用「所有分量模之和」与「最大分量模」。A 是矩阵，它的 1 范数要比较各列模之和。

  2. 算向量 b 的 1 范数

    b 的三个分量是 1、2i、1。纯虚数 2i 的实部是 0，所以 |2i| = √(0² + 2²) = 2。

    ‖b‖₁ = |1| + |2i| + |1| = 1 + 2 + 1 = 4

  3. 逐行乘出 Ab

    每一行都和 b 的三个分量对齐，先相乘，再把三个乘积相加。出现 i·2i 时，先乘出 2i²，再用 i² = −1。

    第一行：1·1 + i·2i + 0·1 = 1 + 2i² + 0 = 1 − 2 = −1。
    第二行：i·1 + (−1)·2i + 2·1 = i − 2i + 2 = 2 − i。
    第三行：0·1 + i·2i + 1·1 = 0 + 2i² + 1 = −2 + 1 = −1。

    Ab = −12 − i−1

  4. 算 Ab 的 ∞ 范数

    只比较三个分量的模。中间分量 2 − i 的实部是 2、虚部是 −1，所以它的模是 √5。两端的 −1 取模后都是 1。

    ‖Ab‖∞ = max(1, √(2² + (−1)²), 1) = √5

  5. 算矩阵 A 的 1 范数

    这次按列看 A。每列都要先取模，再把三个模加起来。注意 |i| = 1、|−1| = 1。

    第 1 列 (1, i, 0)ᵀ：1 + 1 + 0 = 2。
    第 2 列 (i, −1, i)ᵀ：1 + 1 + 1 = 3。
    第 3 列 (0, 2, 1)ᵀ：0 + 2 + 1 = 3。

    ‖A‖₁ = max(2, 3, 3) = 3

  6. 把三个结果相加

    按题目原来的顺序写回去，检查三个量都已算过。

    ‖b‖₁ + ‖Ab‖∞ + ‖A‖₁ = 4 + √5 + 3 = 7 + √5

容易丢分的地方 看到 ‖Ab‖∞ 时，先乘出 Ab。向量 b 的 1 范数和矩阵 A 的 1 范数虽然都写下标 1，计算对象不同。

今晚的收工标准

能闭卷列出第 2 题的方程，并独立算出第 3 题的两行和。第 4 题来不及可以留到明早。

提前看一眼明天的若当标准形

把例题矩阵的右下角 3 改成 2。λ = 2 在特征多项式里出现两次，但 A − 2I 的核只有一维，所以只有一个线性无关的特征向量。这就是明天要区分的代数重数和几何重数。
