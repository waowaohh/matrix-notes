01

先学三个知识点

秩和核空间

先想清楚题目在问什么。求核，就是问「哪些列向量 x 乘上 B 会变成零向量」；求核的维数，就是问「这些解可以由几个独立的方向组合出来」。把矩阵 B 看作方程组的系数。做行变换时，可以交换两行、把某行乘以非零常数，或把某行的倍数加到另一行。这三种操作都能撤销，所以不会改变 Bx = 0 的解。

  1. 先消元。 找到当前列中可用的非零数当主元，把它下面的数消成 0，再往右下处理。零行放到底部。
  2. 再数主元。 阶梯形矩阵有几个主元，秩就是几。没有主元的列对应自由变量。若有 n 列和 r 个主元，核的维数就是 n − r。
  3. 最后回代。 把非零行写回方程。若有两个自由变量 s、t，每次只让其中一个取 1，另一个取 0。具体就是分别取 (s,t) = (1,0) 和 (0,1)，代回去得到两个基向量。再用任意 s、t 写出通解。
基础解系和通解

基础解系是一组向量。通解是把这些向量乘任意系数再相加，表示所有解。

特征值和特征向量

若非零向量 v 满足 Av = λv，λ 就是对应的特征值。把右边移到左边得 (A − λI)v = 0。因为要有非零解，A − λI 必须不可逆，所以先令 det(A − λI) = 0，再对每个 λ 解方程组。

I 是单位矩阵。构造 A − λI 时，只把对角线上的元素减去 λ。三角矩阵可以直接从对角线读出特征值，求特征向量仍要解方程。

向量和矩阵范数

先逐项取模。比如 |2 − 2i| = √(2² + (−2)²) = 2√2。然后看题目里的是向量还是矩阵。

02

从矩阵一步步求特征向量

我们要给下面这个矩阵的两个特征值，各找一个对应的非零特征向量。先把特征值算出来，再把 λ = 2 和 λ = 3 当成两道小题，分别解方程。

A = 4−211

先弄清我们在求什么

这里用 α 表示要找的列向量。题目要求 Aα = λα，意思是「用 A 乘 α」的结果，和「把 α 乘一个数 λ」的结果一样。比如 λ = 2 时，最后要检查的是 Aα = 2α。

为了把未知量 α 放在同一边，引入单位矩阵 E。有的教材也把它写成 I。E 对角线上是 1，其他位置是 0，所以 Eα = α。于是 λα = λEα，从两边减去它，就得到我们要解的方程：

Aα − λEα = (A − λE)α = 0

把特征值 2 和 3 算出来

如果 A − λE 可逆，就能把它的逆矩阵乘到方程两边，得到 α = 0。但零向量不算特征向量，所以要找能让 A − λE 不可逆的 λ，也就是让它的行列式等于 0 的 λ。

A − λE = 4 − λ−211 − λ

二阶行列式用「左上乘右下，再减右上乘左下」。右上角是 −2，所以这里是减去一个负数。

det(A − λE) = (4 − λ)(1 − λ) − (−2)·1
= 4 − 4λ − λ + λ² + 2 = λ² − 5λ + 6 = (λ − 2)(λ − 3)

让这个乘积等于 0，至少有一个因子为 0，因此 λ = 2 或 λ = 3。接下来固定其中一个 λ，未知量只剩向量里的两个坐标。

先求 λ = 2 对应的特征向量

  1. 把 2 代入，算出 A − 2E。

    先把 E 的每个位置乘 2，得到 2E。然后两个矩阵对应位置相减。因为 2E 的非对角位置都是 0，A 的这两个位置照抄。

    E = 1001， 2E = 2002
    A − 2E = 4 − 2−2 − 01 − 01 − 2 = 2−21−1
  2. 写成两条关于 x₁、x₂ 的方程。

    设 α 的上、下两个坐标分别是 x₁、x₂。矩阵的第一行乘 α 得到第一条方程，第二行乘 α 得到第二条方程。右边的两个 0 表示这两条式子都等于 0。

    2−21−1x₁x₂ = 00

    第一行：2·x₁ + (−2)·x₂ = 0。
    第二行：1·x₁ + (−1)·x₂ = 0。

  3. 用行变换消掉重复的方程。

    第一行的两个系数正好都是第二行的两倍。先把第一行除以 2，这相当于把整条方程两边同时除以 2，解不会变。此时两行相同，再用第二行减第一行，就得到一条零行。

    2−21−1 → 1−11−1 → 1−100

    第一条保留下来的方程是 x₁ − x₂ = 0。第二行是 0 = 0，对任何 x₁、x₂ 都成立，所以没有多加一条限制。

  4. 弄清谁可以自己取，再写出所有解。

    第一列有主元，所以 x₁ 由方程决定；第二列没有主元，所以 x₂ 可以任取。把 x₂ 记作 t，则 x₁ = t。比如你选 x₂ = 5，方程就要求 x₁ 也是 5。

    x₁x₂ = tt = t11

    t = 0 时得到零向量；它满足方程，但不是特征向量。为了给出最简单的一个非零解，取 t = 1，得到 α₁ = (1, 1)ᵀ。括号后面的 T 表示转置，提醒我们这两个数应竖着写。

  5. 乘回原来的 A 验算。

    用原矩阵的两行分别乘 α₁。第一行得到 4·1 + (−2)·1 = 2，第二行得到 1·1 + 1·1 = 2。

    Aα₁ = 22 = 211 = 2α₁

    这就确认了 (1, 1)ᵀ 对应的是 λ = 2。

再求 λ = 3 对应的特征向量

现在回到原矩阵 A，重新减 3E。刚才的行化简是为 λ = 2 的方程服务的，换成 λ = 3 后，要从新的系数矩阵开始。

  1. 算 A − 3E 并写出方程。

    对角线上分别做 4 − 3 和 1 − 3，其他位置照抄。

    A − 3E = 4 − 3−2 − 01 − 01 − 3 = 1−21−2
    1−21−2x₁x₂ = 00

    第一行：x₁ − 2x₂ = 0。
    第二行：x₁ − 2x₂ = 0。这是同一条限制。

  2. 去掉重复的行，选自由变量。

    第二行减第一行，得到下面的矩阵。第一列有主元，所以解出 x₁ = 2x₂。第二列没有主元，取 x₂ = t，便得到 x₁ = 2t。

    1−21−2 → 1−200
    x₁x₂ = 2tt = t21

    取 t = 1，得到 α₂ = (2, 1)ᵀ。这里 x₂ 取 1 后，x₁ 得按方程算成 2，不能也顺手写成 1。

  3. 用原矩阵检查它是否放大了 3 倍。

    第一行是 4·2 + (−2)·1 = 6，第二行是 1·2 + 1·1 = 3。

    Aα₂ = 63 = 321 = 3α₂
题目到底要写什么

如果题目要「各写一个特征向量」，就写 λ = 2 对应 (1, 1)ᵀ，λ = 3 对应 (2, 1)ᵀ。如果题目要「全部特征向量」，每个答案都要乘上任意非零数 t。如果题目要「特征空间的一组基」，分别写出只含这一个向量的集合。

接着做第 2 题。每解出一行，试着说出它限制了哪个未知量。等你能说明为什么另一个未知量可以自己取，这一步就会了。

03

独立练四道题

先在空白处或草稿纸上写。卡住时只展开提示。第 3、4 题是按往年题型改编的练习。

01

基础题

行化简求秩和核

B = 121242011

求 B 的秩、核的维数，以及核的一组基。

看起手提示

先把第二行减去第一行的两倍，再把零行移到底部。

看逐步答案与讲解

先读题 这题要交三个结果：秩是一个数，核的维数也是一个数，而一组基要写成向量的集合。核里的向量，就是乘上 B 后变成零向量的 x。

解题路线 把 B 化成阶梯形，用同一个矩阵数主元、找自由变量，再写通解。

  1. 先看 Bx = 0 的三行在说什么

    设 x 是含三个坐标的列向量。B 的每一行乘 x，分别给一条等于 0 的方程。先写出来，你就能看见哪些条件重复了。

    第 1 行：x₁ + 2x₂ + x₃ = 0。
    第 2 行：2x₁ + 4x₂ + 2x₃ = 0。
    第 3 行：x₂ + x₃ = 0。

  2. 消掉重复的第二行

    第二行恰好是第一行的两倍。用第二行减去第一行的两倍，相当于用一条原方程消去另一条里的重复条件。右边也做 0 − 2·0，还是 0。

    (2, 4, 2) − 2(1, 2, 1) = (2 − 2, 4 − 4, 2 − 2) = (0, 0, 0)
    121242011 → 121000011

  3. 把零行移到底部，再数主元

    交换第二行和第三行只是改变方程的排列顺序。现在第一条非零行的首个非零数在第 1 列，下一条在第 2 列，更靠右。矩阵已经是阶梯形，这两个首项就是主元。

    121000011 → 121011000

    有 2 个主元，所以秩是 2。有 3 列，也就是 3 个坐标，只有 2 个主元变量，所以核的维数是 3 − 2 = 1。

  4. 先选 x₃，再从下往上回代

    第 3 列没有主元，所以先把 x₃ 记作 t。选定 t 后，第二条非零行就能算出 x₂；得到 x₂ 后，第一行就只剩 x₁ 待求。零行给出的 0 = 0 不会限制 t。

    由 x₂ + x₃ = 0 得 x₂ + t = 0，所以 x₂ = −t。
    代入 x₁ + 2x₂ + x₃ = 0 得 x₁ + 2(−t) + t = 0。
    合并同类项得到 x₁ − t = 0，所以 x₁ = t。

  5. 写出全部解，再抽出一组基

    把 x₁、x₂、x₃ 按原顺序写回一列，再把共同的 t 提出来。t 任取时得到所有解；只取 t = 1 时，得到一个能生成整个核的非零向量。

    x = (t, −t, t)ᵀ = t(1, −1, 1)ᵀ

    比如取 t = 2 会得到 (2, −2, 2)ᵀ，它只是同一个方向的两倍，不会多出一维。

  6. 用原矩阵检查这个向量

    因为题目问的是原矩阵 B 的核，验算时把 (1, −1, 1)ᵀ 乘回原矩阵。三个分量都应该是 0。

    第 1 行：1·1 + 2·(−1) + 1·1 = 1 − 2 + 1 = 0。
    第 2 行：2·1 + 4·(−1) + 2·1 = 2 − 4 + 2 = 0。
    第 3 行：0·1 + 1·(−1) + 1·1 = −1 + 1 = 0。

卷面答案 rank(B) = 2，dim ker(B) = 1，基础解系为 {(1, −1, 1)ᵀ}。

容易丢分的地方 第三列有非零数，照样可以没有主元。要看每条非零行的第一个非零数落在哪一列。

盖住答案试着说 为什么可以先随便选 x₃，却不能再随便选 x₂？

02

基础题

求特征值和特征向量

C = 1103

求两个特征值，各写出一个对应的非零特征向量。

看起手提示

C 是上三角矩阵。读出特征值后，分别写出 C − I 和 C − 3I。

看逐步答案与讲解

先读题 找出哪两个数 λ 可以让 C 把某个非零向量放大为 λ 倍，并为每个 λ 写一个这样的向量。两个向量要分别和各自的 λ 对上。

解题路线 先找 λ。每找到一个 λ，就回到原矩阵 C，重新算 C − λI、解方程、验算。

  1. 先写出我们要解的式子

    Cv = λv。由于单位矩阵 I 乘 v 还是 v，右边也可以写成 λIv。移到左边，就变成 (C − λI)v = 0。如果 C − λI 可逆，方程只有零解；题目要非零向量，所以要让它的行列式等于 0。

    C − λI = 1 − λ103 − λ
    det(C − λI) = (1 − λ)(3 − λ) − 1·0 = 0

    两个因子至少一个是 0，所以 λ = 1 或 λ = 3。

  2. 固定 λ = 1，写出两个方程

    从 C 的对角线上分别减去 1，得到 1 − 1 = 0、3 − 1 = 2。其余元素照抄。用得到的矩阵乘列向量 x，逐行和零向量对应。

    C − I = 0102
    0102x₁x₂ = 00

    第 1 行：0·x₁ + 1·x₂ = 0，所以 x₂ = 0。
    第 2 行：0·x₁ + 2·x₂ = 0，同样要求 x₂ = 0。

  3. 说明 λ = 1 时哪个坐标可以自己选

    第二行减去第一行的两倍就成了零行。留下的主元在第 2 列，所以方程只固定了 x₂。第一列没有主元，令 x₁ = t。

    0102 → 0100

    所有解是 (t, 0)ᵀ = t(1, 0)ᵀ。取 t = 1，得到 v₁ = (1, 0)ᵀ。

  4. 固定 λ = 3，从原矩阵再算一次

    这次对角线上减去 3，得到 1 − 3 = −2、3 − 3 = 0。上一问的矩阵只适用于 λ = 1，这一步要重新用 C。

    C − 3I = −2100
    −2100x₁x₂ = 00

    第 1 行：−2x₁ + x₂ = 0。
    第 2 行：0·x₁ + 0·x₂ = 0，对任何坐标都成立。

  5. 说明 λ = 3 时为什么取 2 也可以

    第一行除以 −2 后变成 x₁ − x₂/2 = 0。主元在第 1 列，所以按阶梯形的读法，把第 2 列对应的 x₂ 作为自由变量。令 x₂ = t，则 x₁ = t/2。

    −2100 → 1−1/200

    所有解是 (t/2, t)ᵀ。取 t = 1 会得到 (1/2, 1)ᵀ，也正确。为了让两个坐标都是整数，可以取 t = 2，得到 v₂ = (1, 2)ᵀ。

  6. 分别乘回 C，核对两个对应关系

    验算用原矩阵 C。第一组乘积要等于原向量的 1 倍，第二组要等于原向量的 3 倍。

    Cv₁ = (1·1 + 1·0, 0·1 + 3·0)ᵀ = (1, 0)ᵀ = 1·v₁
    Cv₂ = (1·1 + 1·2, 0·1 + 3·2)ᵀ = (3, 6)ᵀ = 3v₂

卷面答案 λ = 1 对应 (1, 0)ᵀ；λ = 3 对应 (1, 2)ᵀ。

容易丢分的地方 自由变量取 1 只是为了方便。任意非零倍数都可以；把自由变量取成 0 得到的零向量不算特征向量。

盖住答案试着说 为什么 λ = 1 时自由变量是 x₁，λ = 3 时却可以按主元位置选 x₂？

03

按往年题型改编

算复矩阵的最大行和

D = 11 + 2i2 − 2i3

求矩阵 ∞ 范数 ‖D‖∞。

看起手提示

分别取四个元素的模。先在每一行内部相加，再在两行之间比较。

看逐步答案与讲解

先读题 题目给的是矩阵 D，要求它的 ∞ 范数。这里要找哪一行的元素取模后加起来最大，最后交一个非负实数。

解题路线 先确认按行算。每行先逐项取模，再相加，最后比较两行。

  1. 先分清取最大值的时机

    第 1 行有两个元素，第 2 行也有两个元素。各自都要算成一个行和，最后比较这两个行和。若题目给的是向量，∞ 范数才直接比较分量的模。

    ‖D‖∞ = max(第一行模之和，第二行模之和)

  2. 算第一行的两个模，再相加

    第一个元素是实数 1，模是 1。第二个元素 1 + 2i 的实部是 1，虚部是 2。复数的模相当于平面上点 (1, 2) 到原点的距离，所以要把两项分别平方后相加再开根号。

    |1| = 1。
    |1 + 2i| = √(1² + 2²) = √(1 + 4) = √5。

    第一行模之和 = 1 + √5

  3. 算第二行的两个模，再相加

    2 − 2i 的虚部是 −2，平方时负号要留在括号里。另一个元素是正实数 3，模就是 3。

    |2 − 2i| = √(2² + (−2)²) = √(4 + 4) = √8 = 2√2。
    |3| = 3。

    第二行模之和 = 3 + 2√2

  4. 比较行和，再核对大小

    第二行的实数项 3 大于第一行的 1，根号项 √8 也大于 √5，因此不用按计算器就能判断第二行更大。

    粗略检查：两行分别约为 3.24 和 5.83，和刚才的比较一致。

    ‖D‖∞ = 3 + 2√2

卷面答案 ‖D‖∞ = 3 + 2√2。

容易丢分的地方 先取模再相加。假如一行里有 1 和 −1，这一行的模之和是 2，先把数相加再取模会错算成 0。

盖住答案试着说 为什么这题先得到两个行和，而不是从四个元素中挑最大的一个？

04

按往年题型改编

分开算三种范数

A = 1i0i−120i1， b = 12i1

求 ‖b‖1 + ‖Ab‖∞ + ‖A‖1。

看起手提示

先算 b 的模之和，再算 Ab。最后一项按列求和。

看逐步答案与讲解

先读题 一共有三项。第一项看列向量 b，第二项看乘出来的列向量 Ab，第三项看矩阵 A。它们有的用同一个下标，规则却要看对象。

解题路线 把每项当成一小题。先完成 b，再算 Ab 和它的范数，最后算 A 的范数并相加。

  1. 先给三个对象分配算法

    b 和 Ab 都只有一列。向量的下标 1 表示把所有分量的模加起来，下标 ∞ 表示只取其中最大的模。A 有三行三列，它的 1 范数要先给每列各算一个模之和。

    ‖b‖₁：取模后加。
    ‖Ab‖∞：先乘出向量，取模后挑最大。
    ‖A‖₁：按列取模求和，再挑最大列和。

  2. 先算 b 的三个分量的模

    b 的中间分量是 2i，它的实部为 0，虚部为 2，所以模是 √(0² + 2²) = 2。两端的 1 取模后还是 1。

    ‖b‖₁ = |1| + |2i| + |1| = 1 + 2 + 1 = 4

  3. 逐行算出 Ab 的三个分量

    A 的每一行有三个数，b 也有三个分量。一行与 b 对应相乘再相加，得到一个分量。有三行，就得到三个分量。遇到 i·2i，先合成 2i²，再用 i² = −1。

    第 1 行：1·1 + i·2i + 0·1 = 1 + 2i² + 0 = 1 − 2 = −1。
    第 2 行：i·1 + (−1)·2i + 2·1 = i − 2i + 2 = 2 − i。
    第 3 行：0·1 + i·2i + 1·1 = 0 + 2i² + 1 = −2 + 1 = −1。

    Ab = −12 − i−1

  4. 给 Ab 的三个分量取模，再取最大

    现在已经有了一个向量，不再按矩阵的行来求和。两端都是 −1，模是 1；中间的 2 − i 要把实部 2、虚部 −1 分别平方。

    ‖Ab‖∞ = max(1, √(2² + (−1)²), 1) = max(1, √5, 1) = √5

  5. 回到 A 从上到下读每一列

    第三项只需要 A 的元素。每一列从上到下取模再相加。比如第 2 列是 i、−1、i，这三个元素的模都是 1。

    第 1 列：|1| + |i| + |0| = 1 + 1 + 0 = 2。
    第 2 列：|i| + |−1| + |i| = 1 + 1 + 1 = 3。
    第 3 列：|0| + |2| + |1| = 0 + 2 + 1 = 3。

    ‖A‖₁ = max(2, 3, 3) = 3

  6. 加起来，用另一种方式核对乘积

    把三项按题目顺序相加。再抽查最影响答案的中间分量：也可以把 Ab 理解为用 b 的分量给 A 的三列加权。取这个和的第 2 个坐标，得到 1·i + 2i·(−1) + 1·2 = 2 − i，和逐行乘出来的一致。

    ‖b‖₁ + ‖Ab‖∞ + ‖A‖₁ = 4 + √5 + 3 = 7 + √5

卷面答案 7 + √5。

容易丢分的地方 下标 1 不等于固定一种算法。对 b 的分量取模后全部相加；对 A 要先区分列，再取最大列和。
